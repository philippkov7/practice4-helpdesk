# BDD-сценарии

## 1. Создание заявки

Дано (Given): открыта страница HelpDesk, в списке есть 4 заявки.

Когда (When): пользователь заполняет форму:
- тема — «Сбой учебного принтера»;
- описание — «Принтер в аудитории 205 не печатает документы»;
- категория — «Оборудование»;
- приоритет — «Высокий».

Затем нажимает «Создать заявку».

Тогда (Then): появляется сообщение «Заявка №5 создана».
В списке становится 5 заявок. У новой заявки указаны
введённые данные и статус «Новая».

Проверяется тестом E-01 в файле cypress/e2e/tickets.cy.js.

## 2. Слишком короткая тема

Дано (Given): список заявок пуст.

Когда (When): через API отправляется заявка:
- тема — «Сбой»;
- описание — «Принтер в аудитории не отвечает»;
- категория — hardware;
- приоритет — medium.

Тогда (Then): сервер возвращает код 400 и сообщение
«Тема должна содержать от 5 до 80 символов».
Заявка не сохраняется, список остаётся пустым.

Проверяется тестом I-02 в файле tests/integration/api.test.js.

## 3. Поиск с фильтрами

Дано (Given): на странице есть 4 исходные заявки.

Когда (When): пользователь выбирает приоритет «Высокий»,
статус «Новая», категорию «Сеть» и вводит в поиск «vpn».

Тогда (Then): в списке остаётся только «VPN недоступен».
Счётчик показывает 1.

Когда (When): пользователь меняет приоритет на «Низкий».

Тогда (Then): подходящих заявок нет. Счётчик показывает 0.

Проверяется тестом E-05 в файле cypress/e2e/tickets.cy.js.
